Shaw Cupcakes

Purpose

Shaw Cupcakes is a website I created for a local bakery cupcake business. The goal was to build a clean, friendly web presence that could introduce the brand, highlight the products, and make the business feel more professional online.

This project helped me learn Bootstrap 5 while connecting HTML and CSS together in a real layout. I focused on core HTML principles, CSS structure, spacing, sections, and responsive behavior while using a framework to speed up my workflow.

I also practiced small JavaScript features, including dropdown behavior, so the page could feel more interactive. It gave me a better understanding of how HTML, CSS, Bootstrap components, and JavaScript can work together inside one project.
